# Character Atlas Core

キャラクターを名前・ステータスで一覧表示し、効果・タグで詳細検索する Java 25 LTS / Gradle の共通プロジェクト。

- `domain` はキャラクター、スキル、検索語、根拠を定義する。
- `application` は一覧・詳細・詳細検索のユースケースと、データを読み込む `CatalogRepository` を定義する。
- `src/main/resources/db/migration` は共通 PostgreSQL スキーマの Flyway マイグレーション。公開側にも移せる汎用の定義だけを含む。

このディレクトリ単体で `./gradlew test` を実行できる。JUnitはAND／OR、根拠を使った結果順、欠損ステータス、名前の正規化を検証する。

## 検索順の暫定ルール

ANDでは全条件が明示参照で揃うキャラクターを優先する。ORでは明示参照が少なくとも1件あるキャラクターを優先する。一覧の初期順と詳細検索の各グループ内は図鑑優先度順。同じ優先度はID順、図鑑優先度が未収録のものは末尾に置く。設定上の明示参照と、実際に効果が発動することは区別する。

データソースは利用側が差し込む。テストには架空の値だけを使う。
